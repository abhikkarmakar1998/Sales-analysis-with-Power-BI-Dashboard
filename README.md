# Sales Performance Dashboard (Power BI)

## Project Overview
This project analyzes company-wide sales performance using **Power BI**. The dashboard provides an executive view of sales, profitability, product performance, and monthly sales trends to support business decision-making.

## Dashboard Preview

![image alt]([dashboard.png](https://github.com/abhikkarmakar1998/Sales-analysis-with-Power-BI-Dashboard/blob/8dfca82dd385d638a67c2420755e9d337d850ea1/Dashboard.png))

## Key KPIs
- **Total Sales:** ₹19.81 Million
- **Total Cost:** ₹14.82 Million
- **Total Profit:** ₹4.99 Million
- **Profit Margin:** 25.2%

## Dashboard Features
- Monthly Sales Trend
- Product-wise Sales Analysis
- Regional Performance
- KPI Cards (Sales, Profit, Margin)
- Interactive slicers for Year and Region

## Key Business Insights
- Generated **₹19.81M** in total sales with a **25.2%** profit margin.
- Sales fluctuate throughout the year, indicating seasonal demand.
- Laptops and Printers are the strongest-performing products.
- Revenue is concentrated among a few high-performing products.
- Effective cost management supports healthy profitability.

## Business Recommendations
1. Strengthen marketing during slower months.
2. Maintain inventory for top-selling products.
3. Improve low-performing product categories.
4. Continue optimizing operational costs.
5. Improve demand forecasting using historical trends.
